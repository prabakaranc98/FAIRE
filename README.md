# FAIRE — Frontier AI Research Encyclopedia

> wiki + paperwithcode + MVB nudge — in one system

A knowledge base where every concept page links to something you can build, and every build page compounds into the next build. Content is generated by a local LangGraph agent harness, not written by hand.

---

## Three layers, three modes of engagement

**Curriculum** (`docs/curriculum/`) — *Range*
One page per concept, organized across 15 tracks. Theory, math, papers, production examples, open questions. Every page ends with "This concept appears in" — links to the arc steps that use it. No builds here. Go here to understand something deeply.

**Arc Index** (`docs/arcs/{arc}/index.md`) — *Depth*
Opinionated paths from a starting concept to a frontier capability. Each arc = a sequence of chapters with curated readings, a compounding trajectory table, and step-by-step build progression. Go here when you want a guided path to something real.

**Arc Steps** (`docs/arcs/{arc}/step-NN-*.md`) — *Execution*
One build per page. Each build's artifact is literally what the next step loads — the compounding is not metaphorical. Every step page has a recipe with sanity checks, expected output with specific shapes and numbers, failure modes, and open questions raised by the build. Go here to build.

---

## How the layers connect

```
Curriculum ──backlinks──► Arc Step ──► Arc Step ──► Arc Step ──► (destination)
    ▲                         │
    └─────── Go deeper ───────┘

Arc Index lists all steps → Arc Step links to Arc Index breadcrumb
Arc Step links to curriculum pages for the theory behind the build
Curriculum pages link to arc steps that use the concept
```

## The editorial agent pipeline

Every page is written by a local LangGraph agent. The pipeline:

```
START
  → load_persona        per-track expert persona (YAML)
  → read_stub           existing content if page already exists
  → research            Exa neural search: foundational papers + 2024–25 SotA
                        Exa find_similar: expand from top arxiv seeds
                        HuggingFace: models + datasets
  → plan_and_scratch    planning + fact-sheet compilation
                        (writer never sees raw search results)
  → write_arc_step      arc step pages — recipes + compounding artifacts
  → write_arc_index     arc index pages — chapters + trajectory tables
  → write_draft         curriculum pages — theory + open questions + arc backlinks
  → review              schema · source policy · prose · open questions · backlinks
                        ReviewResult confidence 0–1
  → [conf ≥ 0.8]  → write_file → commit → log_run → END
  → [conf < 0.8]  → revise_draft → review (max 2 revisions)
  → [still failing] → flag_human_review → log_run → END
```

Three write modes route from `plan_and_scratch`:
- `mode == "arc-step"` → `write_arc_step_node` (has_mvb: true, compounding contract enforced)
- `mode == "arc-index"` → `write_arc_index_node` (destination + chapters + trajectory table)
- default → `write_draft_node` (curriculum, has_mvb: false, open questions required)

## Running the agents

```bash
# 1. Clone and set up
git clone https://github.com/prabakaranc98/FAIRE.git && cd FAIRE
cd agents && uv sync

# 2. Configure API keys (never committed)
cp .env.example .env
# Fill in: OPENROUTER_API_KEY, EXA_API_KEY

# 3. Generate one page from the sprint queue
uv run python generate.py

# 4. Generate a specific page directly
uv run python generate.py generate \
  --topic vae-mnist \
  --mode arc-step \
  --arc generative-stack

# 5. Start the self-improving 48h cycle
uv run python server.py --run-now

# 6. Preview the wiki locally
cd .. && mkdocs serve
```

The sprint queue lives in `agents/sprints/current.md`. 57 arc step items + 14 priority curriculum updates are queued. Edit it to reprioritize.

## Security constraints

- API keys in `agents/.env` only — never committed (gitignored)
- Agents run LOCAL ONLY — not deployed online
- Source policy: `arxiv.org`, `*.edu`, `huggingface.co`, official library docs only
- "In production" sections also allow official lab engineering blogs
- NEVER cite: Medium, Towards Data Science, personal blogs, Substack, Wikipedia
- Reviewer enforces source policy on every run
