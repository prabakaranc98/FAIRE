## How to access live data

- **JSON metrics**: `GET http://localhost:8765/metrics`

- **Budget state**: `GET http://localhost:8765/budget`

## Control system

The observer is the **sensor layer** of the closed-loop feedback controller:

```
Observer (sensor) → Supervisor (controller) → Pipeline (actuator) → log_run (feedback)
```

Set points:

| Signal | Target |
|---|---|
| Coverage | ≥ 80% of stubs generated |
| Quality | avg reviewer confidence ≥ 0.85 |
| Staleness | 0 pages older than 180 days |
| Budget | > $1.00 remaining |

Error signals (deviations from set points) feed directly into supervisor priority weights.
