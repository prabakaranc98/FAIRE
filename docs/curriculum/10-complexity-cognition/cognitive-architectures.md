# Cognitive Architectures
> **TL;DR:** Computational theories of how the mind is organized — from ACT-R's production rules to Global Workspace Theory — and how they inform the design of AI systems that reason, plan, and remember.

> 🚧 Agent-generated content pending. See [track index](index.md) for context.

## Core concepts
- **ACT-R** — Anderson's cognitive architecture; modules for memory, perception, action, production rules
- **SOAR** — Unified theory of cognition as problem solving; impasses trigger chunking of new knowledge
- **Global Workspace Theory** — Baars/Dehaene; a central "workspace" broadcasts to specialized modules
- **Dual-process theory** — System 1 (fast, automatic) and System 2 (slow, deliberate); Kahneman
- **Working memory** — limited-capacity short-term store; the bottleneck in cognitive processing
- **Executive control** — top-down regulation of cognitive processes
