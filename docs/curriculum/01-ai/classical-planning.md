## Why it matters at the frontier
Planning is resurging in modern AI: LLM agents doing multi-step reasoning, tree-of-thought, and neurosymbolic systems all draw on classical planning ideas.

## Core concepts
- **STRIPS** — the first formal planning language; actions have preconditions and effects
- **PDDL** — Planning Domain Definition Language; the standard for expressing planning problems
- **State space** — set of all world states; planning = finding a path from initial to goal state
- **Forward search** — progressively apply actions from initial state to reach goal
- **Backward search** — work backward from goal, identify which actions achieve subgoals
