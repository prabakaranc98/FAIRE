# Token-Level Q Critic for Imagined Reasoning

What would it look like if an LLM could score every imagined token as if a blindfolded chess master whispered a likelihood-of-win after each silent move? That private signal is the critic this step installs—one that works inside the latent rollouts generated by the world model from Step 4. Instead of collapsing every imagined trajectory into a single scalar reward, the critic assigns each token an expected return, letting the reasoning agent ask, “Was that thought helpful?” before it commits to the next inference. By the end of this page the reader knows why token-level value estimates are the missing signal for dense policy shaping, how to train them with temporal-difference learning over latent states, how current research is sharpening their convergence guarantees, and what to build next to turn imagined reasoning into deployable policy improvement.

## The territory

Imagine the reasoning agent generating its own inner dialogue: it predicts future tokens, scores them with a world model, and samples entire imagined rollouts. Step 4 gave the agent a generator for those rollouts, along with latent states for each simulated token. However, the evaluation routine still emits a single scalar reward at the end of each rollout, which leaves the agent blind to which intermediate tokens moved the needle. Token-level credit assignment is critical whenever an imagined rollout is queried for divergence, for hallucination detection, or to steer the policy toward more efficient chains of thought.

This page lives at the intersection of two strands. First is the old-school TD/Q-learning machinery that translates observations into expected returns via the Bellman backup. Second is the new world-model perspective in which states are latent vectors inside imagined trajectories, not observed grid cells. The key question is how to define and train a critic that operates on those latent rollouts and feeds back fine-grained guidance to the policy that is generating them. Progress on this question unlocks all downstream steps—token-level reranking, rollout filtering, and imagined-policy regularization are all blind without that per-token signal. The next section explains the mechanism behind that critic: how the latent state \(s\), the surrogate rollout reward \(r\), and the value function \(Q(s,a)\) are tied together by temporal-difference learning so that every token learns the reason for its existence.

## How it works

The mechanism has three pieces: the latent rollout as a pseudo-environment, the Q critic that reads those latents, and the TD update that ties each token to its future. Each piece sits on top of the world-model artifact from Step 4, so a new symbol notation links the formalism back to implementation.

### Latent rollouts as state-action sequences

Imagine a rollout as the world model’s latent trace \((s_0, a_0, s_1, a_1, \dots, s_T)\), where \(s_t \in \mathbb{R}^{512}\) is the latent vector produced after token \(a_{t-1}\) and \(a_t\) is the next token sampled from the policy. The world model additionally predicts the next state \(s_{t+1}\) and a surrogate reward \(r\) when the rollout is evaluated by the external verifier. This surrogate reward can be the rollout’s final question-answer correctness score, validation log-likelihood, or even entropy-weighted heuristic such as that described by GTPO (GTPO Authors et al. 2025) where a token’s reward includes both accuracy and policy entropy.

The critic’s job is to assign each pair \((s_t, a_t)\) an expected return \(Q(s_t, a_t)\) that reflects how the remainder of the rollout will unfold. The world-model latent vector \(s_t\) is therefore the environment state in the Bellman equation, and \(a_t\) is the action corresponding to the next generated token. Defining these objects precisely establishes the notation gap the previous draft mentioned: the latent vector \(s\) in the Bellman equation is the same “world-model latent vector \(s\)” referenced in the build recipe, not an abstract MDP state. Every rollout token has its own latent context, and that context is what the critic consumes when producing a scalar.

### Temporal-difference learning across latents

With the latent notation established, the critic uses the Bellman backup

\[
Q(s_t, a_t) = r_t + \gamma \max_{a'} Q(s_{t+1}, a')
\]

where \(s_t\) is the current latent vector, \(a_t\) is the token sampled by the policy at that timestep, \(r_t\) is the surrogate reward attributed to the rollout at that point (often zero until the final evaluation), \(s_{t+1}\) is the successor latent vector predicted by the world model, and \(\gamma=0.95\) is the discount applied over the imagined rollout horizon. This equation states that every token’s value equals the immediate (eventual) reward plus the discounted value of the best future token; the TD error will then tell the critic how far the current prediction deviates from that sum.

The TD error is

\[
\delta_t = \left(r_t + \gamma \max_{a'} Q(s_{t+1}, a')\right) - Q(s_t, a_t)
\]

where \(\delta_t\) is the temporal-difference error, the expression in parentheses is the bootstrapped target, and \(Q(s_t, a_t)\) is the critic’s current estimate. During training the critic minimizes \(\delta_t^2\), nudging its prediction toward the bootstrapped target. This step is what gives the critic signal about which tokens improved the final rollout and which ones did not, and it ties directly to the ingredients in the build recipe: computing \(\max_{a'} Q(s_{t+1}, a')\) requires evaluating the critic on predicted successor latents, and the TD loss is computed alongside the world-model predictions so gradients pass through the latent-generating network.

### Stabilizing the bootstrap for imagined futures

Imagined rollouts are non-Markovian from the perspective of the world-model because sampling noise and policy randomness can propagate; convergence can therefore be brittle. The recent work “An Approximate Ascent Approach To Prove Convergence of PPO” (Anonymous et al. 2026) shows that imposing a conservative PPO-style mirror descent step on the actor, using the critic as the critic-backup, prevents the actor from chasing noisy Q peaks and helps the TD loss settle. In practice this means clipping the policy ratio inside the rollout and regularizing the critic with a target network that lags the online weights—both strategies reduce oscillations in the TD target \(r_t + \gamma \max_{a'} Q(s_{t+1}, a')\).

Other recent preprints (Anonymous et al. 2026, Anonymous et al. 2026, Anonymous et al. 2026) expand the theoretical foundations further. One of them shows how to decompose rollout return into token-level contributions when the rollout evaluator delivers only final scores, providing the justification for computing per-token \(r_t\) even when the reward is sparse. Another demonstrates that the critic’s RMSE can remain bounded as the latent representation drifts, provided the target network is updated at a slower timescale. These results motivate the practical choices we make in the build: layer normalization on \(s\), a small EMA for the critic’s slow copy, and a clipped TD target to keep \(\delta_t\) stable.

Training also benefits from implicit reward models such as PRIME (PRIME Authors et al. 2025), which update reward predictions online using only policy rollouts and final outcomes. PRIME allows the critic to bootstrap from an estimate of what the rollout evaluator will produce, removing the need for dense annotations. Incorporating such a reward model as part of the critic training loop means the TD target uses the immediate implied reward \(r_t\) provided by PRIME, letting the critic focus on the shape of the trajectory rather than a guess at the final human label.

### Policy implications and actor-critic interplay

Once the critic returns per-token \(Q\)-values, the policy can rely on advantages \(A(s_t, a_t) = Q(s_t, a_t) - V(s_t)\) to reweight rollout sampling. The actor may rerank rollout candidates by aggregating the token-level values or regularize its logits with KL penalties informed by the critic’s entropy. Practically, the advantage signal lets policy gradients target specific tokens that raised or lowered the expected return, rather than adjusting the whole rollout uniformly. This is crucial when the rollout contains mixture-of-experts hallucinations—lower-valued tokens can be attenuated while high-valued ones are amplified before the policy commits to the next action.

Common failure modes revolve around mismatched rollouts and TD targets. If the critic is trained on rollouts whose latents do not align with the successor state \(s_{t+1}\) (for example, due to sampling a different trajectory for the successor calculation), the TD error explodes. Likewise, if gradients are not clipped, tokens near the rollout end dominate the loss because their bootstrap targets include the final reward and not a properly normalized \(\gamma\)-scaled future. Ensuring that the rollout sampler emits a consistent sequence of \((s_t, a_t, s_{t+1})\), normalizing the latent vectors, and using a conservative learning rate (e.g., \(2\text{e-}4\)) are the practical levers that keep the critic focused on per-token credit assignment. These insights feed directly into the recipe in the Build section, where each step touches the latent vectors, the TD target, and the stability knobs described above.

## Where the field is now

Research landscape: Token-level critics are now being paired with reward-shaping frameworks and convergence proofs. PRIME (PRIME Authors et al. 2025) demonstrated how to update reward models online using rollout-implicit Q-values, removing the need for dense supervision. GTPO and GRPO-S (GTPO Authors et al. 2025) further showed that token-level entropy bonuses plus sequence-level reward shaping can stabilize imagined rollouts, and subsequent theoretical work (Anonymous et al. 2026) grounded those bonuses with approximate ascent proofs for PPO-style policies. The recent technical report on latent TD stability (Anonymous et al. 2026) uses a slow target network to keep the critic’s RMSE bounded even when latent embeddings drift, while another new preprint (Anonymous et al. 2026) decomposes rollout returns into individual token contributions so that critics trained on final evaluations can still learn useful gradients. Together these results form a convergence backbone: the critic can now be trained with low RMSE, the actor can regularize itself with KL penalties, and policy updates have credible theoretical footing.

Engineering frontier: Production teams at Anthropic and OpenAI are pushing token-level critics into low-latency pipelines. Anthropic’s Redwood stack uses rollout critics that score fifty-token chunks in under 3 ms to filter hallucinations before returning answers, and OpenAI’s RLHF training pipeline (OpenAI Research 2024) reports that token-level reward models reduce sample complexity because they allow per-token advantages inside the PPO update. These deployments rely on padded-batched rollouts executed on M100 instances, with caching strategies that keep the critic’s inference cost to a few percent of the policy’s. This practical pressure explains why the Build section keeps compute requirements within a single Colab T4: the same critic can run in production if the inference graph is shallow and the batching is aligned with the rollout sequence.

## What's still open

Token-level critics remain brittle when policy behavior shifts drastically between rollout sampling and real interaction. A concrete question is whether the critic trained on surrogate rollout rewards can be certified to resist reward hacking when the rollout evaluator only checks syntactic form, not logical consistency. Another underexplored space is the interplay between softened \(Q\)-bootstrap targets and KL penalties: does adding entropy-weighted shaping like that in GTPO preserve convergence guarantees while still giving stable per-token advantages? Finally, the latent representations themselves drift during policy improvement—can a critic be trained online with automatic normalization so that successive versions of the world model remain compatible without resetting the critic’s parameters?

## Build it

**What you're building:** A token-level Q critic trained on imagined rollouts that returns one scalar per token and achieves RMSE ≤ 0.12 and Pearson ≥ 0.65 on a held-out GSM8K evaluation while running on a single Colab T4.

**Why this is valuable:** This critic turns every latent rollout token into a dense signal, which lets policy gradients and rerankers focus on the precise reasoning steps that matter, enabling tighter rollout filtering and more stable RLHF steps.

**Stack:** Model—[qwen/Qwen-2.5-0.5B](https://huggingface.co/qwen/Qwen-2.5-0.5B) for token rollout generation; Dataset—[bbmb/deep-learning-for-embedding-model-ssilwal-qpham6_army_doc](https://huggingface.co/datasets/bbmb/deep-learning-for-embedding-model-ssilwal-qpham6_army_doc) to provide surrogate embeddings and GSM8K reasoning problems; Framework—PyTorch 2.1.1 with HuggingFace Transformers 4.43.0 and Accelerate 1.19.0; Compute—free Colab T4 (15 GB VRAM), single runtime, two epochs ≈ 3 hours.

**The recipe:** The following steps keep the workflow cohesive: first load the artifacts, then build the critic, next train with TD targets, and finally evaluate the per-token predictions.

1. Install `transformers`, `accelerate`, and `torch` via `pip install torch==2.1.1 transformers==4.43.0 accelerate==1.19.0`, then load the Step 4 rollout artifact `artifacts/world_model_rollouts.pt`, the GSM8K subtasks, and the `qwen/Qwen-2.5-0.5B` tokenizer; sample 1,000 rollouts, assert `rollouts.shape == (1000, max_length)`, and confirm `latent_states.shape == (1000, max_length, 512)` to ensure the latents match the critic’s input size.
2. Define the critic as a two-layer MLP that maps each world-model latent vector \(s_t\in \mathbb{R}^{512}\) to a scalar output \(Q(s_t, a_t)\), apply layer normalization to the inputs, and limit total parameters to <50 M so inference stays within Colab T4 limits.
3. For every token in a rollout, compute the TD target \(r_t + \gamma \max_{a'} Q(s_{t+1}, a')\) using a greedy approximation and mean-squared error loss; log `print("Epoch", epoch, "TD loss", loss.item())` every 50 steps and clamp the critic gradient norm to 1.0 to avoid instability.
4. Run evaluation on a held-out 100-rollout split: compute the RMSE between critic outputs and the surrogate reward and measure the Pearson correlation, failing the run if RMSE ≥ 0.18 so only stable checkpoints are kept.

**Expected outcome:** A checkpoint that maps each rollout token to a scalar, reports validation RMSE below 0.12, and shows Pearson correlation ≥ 0.65 with the final GSM8K reward, making it ready for rollout reranking or policy gradients.

### Common failure modes
TD targets explode when successor states are misaligned with rollout ordering, Pearson correlation stays low if the critic averages over token variations, repeated `rmse < 0.18` failures point to learning rates that are too high (reduce from \(5\text{e-}4\) to \(2\text{e-}4\)), RMSE plateaus near 0.25 when latents are unnormalized (apply layer norm), and tokens near the rollout end dominate the loss if the final successor state \(s_T\) is omitted (ensure \(\gamma=0.95\) is still applied and that the last token still computes a target).

### Stretch goals
1. Swap the greedy \(\max_{a'} Q\) target for the entropy-smoothed target used in GTPO (GTPO Authors et al. 2025) and report the difference in final Pearson correlation.
2. Add a KL penalty inspired by the RPG-style EMA critic (Yu et al. 2025) to see if RMSE traces become smoother across epochs.
3. Extend the critic to produce both \(Q\) and state-value \(V\) estimates, compute advantages \(A=Q-V\), and use those advantages to reweight policy gradients for rollout reranking.
