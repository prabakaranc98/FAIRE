# Learning Arcs

Themed paths that cut across curriculum tracks. Each arc is a logical sequence: a coherent journey from entry point to deep understanding of a connected set of ideas.

Arcs are not courses — they're navigational guides. Follow the order or jump in at the right depth.

---

| Arc | What it covers |
|---|---|
| [MLP to Transformer](mlp-to-transformer/index.md) | The full architecture lineage: from perceptrons to attention to modern transformers |
| [Generative Stack](generative-stack/index.md) | VAEs → GANs → diffusion → flow matching — the evolution of deep generative models |
| [Language Models](language-models/index.md) | Pretraining, alignment, RLHF, scaling laws, and frontier LLM research |
| [Causal AI](causal-ai/index.md) | From correlation to causation: SCMs, do-calculus, causal representation learning |
| [Reinforcement Learning](reinforcement-learning/index.md) | Value functions → policy gradients → model-based RL → RLHF |
| [Systems for Scale](systems-for-scale/index.md) | Distributed training, inference optimization, hardware-ML co-design |
| [Scientific AI](scientific-ai/index.md) | Neural operators, physics-informed learning, protein structure, simulation |
